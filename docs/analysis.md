# 듀오링고 리버스 엔지니어링 분석 (REA)

조사 방법: duolingo.com(ko) 실제 접속 → DOM 스냅샷 + 스크린샷 캡처 (ego-browser → Chrome).
캡처 완료: 랜딩, 코스 카탈로그, 온보딩 4단계, **레슨 플레이어(그림 4지선다)**,
**정답 피드백 시트**, **오답 피드백 시트 + 하트 차감 모달**.
미캡처(지식 기반 구현): 학습 경로, 결과 화면, 단어은행/듣기/짝맞추기 문제.

## 1. 정보 구조 (IA)

```
비로그인  랜딩 → 온보딩(코스/목적/목표/레벨) → 첫 레슨 체험 → 가입 유도
로그인   [학습]  경로(Path) → 레슨 플레이어 → 결과
         [퀘스트] 일일/주간 미션
         [리그]  주간 XP 리더보드 (승급/강등)
         [상점]  젬으로 하트·스트릭 프리즈 구매
         [프로필] 통계·업적·코스 전환
```

내비게이션: 데스크톱 = 좌측 고정 사이드바 + 우측 레일(스트릭/젬/하트/리그 위젯),
모바일 = 하단 탭바. 레슨 중에는 내비게이션이 전부 사라지고 전체화면 몰입.

## 2. 핵심 화면 구조

### 2-1. 온보딩 (실측)
- 상단: `← 뒤로` + 얇은 **진행 바**(녹색, 라운드), 좌우 여백 큼
- 본문: **마스코트 + 말풍선**(꼬리 달린 흰 버블, 1px 테두리)으로 질문 제시
- 선택지: 2열 그리드 **옵션 카드** — 흰 배경, 2px 테두리 `#E5E5E5`,
  하단에 4px 짙은 테두리(입체감), radius 12px, 아이콘 + 라벨
- 하단: 상단 1px 구분선이 있는 **고정 푸터** + 우측 정렬 CTA
- CTA는 선택 전 **disabled(회색)**, 선택 후 활성 → 전환 명확

### 2-2. 학습 경로 (Path)
- 유닛 헤더 배너: 유닛 번호/제목 + 가이드북 버튼, 유닛 색상으로 배경 채움
- 노드가 **지그재그 곡선**으로 배치. 노드 상태:
  `잠김(회색)` / `현재(컬러+바운스+"시작" 말풍선)` / `완료(체크)` / `금관(레전더리)`
- 노드 = 두꺼운 원형 버튼 + 아래쪽 그림자(눌리는 느낌), 둘레에 진행 링
- 노드 탭 → 팝오버(레슨명, N/M 레슨, 시작 버튼)
- 중간에 보물상자/캐릭터 장식, 섹션 전환 배너

### 2-3. 레슨 플레이어 (실측)
- 상단바: `✕` | **진행 바**(녹색, radius 999, 안쪽에 밝은 하이라이트 띠) | `♥ 5`
- 문제 머리: 작은 **"새로운 단어" 뱃지**(보라 아이콘+보라 텍스트) → 그 아래 굵은 질문문
- 보기: 카드 3~4개 가로 배열. 각 카드 = 그림 + 하단에 `라벨` + 우측 **숫자 단축키 뱃지**
  → 키보드 `1·2·3` 선택, `Enter` 제출/계속. **키보드만으로 레슨 전체 진행 가능**
- 하단: 1px 상단 구분선 고정 푸터 — 좌측 `건너뛰기`(회색 고스트), 우측 `확인`(미선택 시 disabled)
- 제출 후 **피드백 시트**가 푸터 영역을 덮으며 올라옴 (실측)
  - 정답: 연녹색 배경 + 흰 원 안 초록 체크 + **"잘하셨어요!"** + 초록 `계속하기`
  - 오답: 연분홍 배경 + 흰 원 안 빨강 ✕ + **"정답:"** 레이블 + 정답 텍스트 + 빨강 `계속하기`
  - 공통 보조 링크: `너무 쉬워요 · 너무 어려워요 · 신고하기`
  - 선택한 보기 카드도 초록/빨강으로 함께 물듦 (피드백 **이중 표시**)
- 첫 오답 시 **하트 모달**: 하트 5개(1개 회색) + "오답 한 개마다 하트를 하나 잃게 됩니다!"
  + 보조 설명 + `계속 학습하기`. 상단 하트 카운터는 **흰 원으로 팝업되며 숫자 감소 애니메이션**
- 틀린 문제는 **큐 뒤쪽에 재삽입**(완전 숙달 전까지 반복)

### 2-4. 결과 화면
- 3개 통계 타일: `총 XP` / `정확도` / `소요 시간`
- 콤보/퍼펙트 보너스, 일일 목표 링 증가 애니메이션

## 3. 문제 유형 (레슨 엔진)

| # | 유형 | 상호작용 | 채점 |
|---|------|----------|------|
| 1 | 그림 단어 선택 | 이미지 4지선다 | 정확 일치 |
| 2 | 번역(단어 은행) | 타일 탭해서 문장 조립 | 토큰 순서 일치 |
| 3 | 번역(직접 입력) | 텍스트 입력 | 정규화 후 비교(대소문자/구두점/다중 정답) |
| 4 | 듣기 받아쓰기 | TTS 재생 + 타일 조립 | 토큰 순서 일치 |
| 5 | 짝 맞추기 | 좌우 탭 매칭 | 전부 매칭 시 통과 |
| 6 | 빈칸 채우기 | 문장 내 선택지 | 정확 일치 |
| 7 | 말하기 | 마이크 | (본 구현에서는 읽기 확인으로 대체) |

레슨 1회 = 문제 10~15개, 유형을 섞어 출제. 오답은 재출제 큐로.

## 4. 게임화 시스템

- **하트** 5개. 오답 1개당 -1, 0이면 레슨 진입 불가.
  회복: 시간 경과(≈4시간/1개), 젬 350개, 연습 레슨 완료
- **XP**: 레슨 10 XP + 퍼펙트 보너스. 일일 목표(10/20/30/50 XP) 링으로 표시
- **스트릭**: 일일 목표 달성 시 +1. 스트릭 프리즈로 1일 방어
- **젬**: 레슨/퀘스트 보상, 상점 재화
- **리그**: 주간 XP 기준 30명 그룹, 상위 승급 / 하위 강등 (브론즈→…→다이아)
- **퀘스트**: 일일 3종(“XP 20 획득”, “레슨 2회”, “퍼펙트 1회”)
- **업적 배지**: 누적 XP, 스트릭, 퍼펙트 등 단계별 레벨

## 5. 비주얼 토큰 (원본 실측)

- 폰트: Feather Bold 계열, 매우 두꺼운 웨이트, 자간 좁음
- 브랜드 그린 `#58CC02`, 눌림 그림자 `#58A700`, 보더 `#E5E5E5`, 텍스트 `#4B4B4B`
- 버튼: radius 12~16px, **하단 4px 솔리드 그림자**, 누르면 그림자 0 + 2px 아래로 이동
- 카드: 2px 보더 + 하단 4px 보더, 선택 시 테두리/배경이 브랜드 틴트로
- 전면 대문자 CTA, 넉넉한 여백, 일러스트 중심

## 6. Pingo에서의 교체 방침 (UI 전면 교체)

| 항목 | 듀오링고 | Pingo |
|------|----------|-------|
| 마스코트 | 초록 올빼미 Duo | 보라 펭귄 **핑고** (인라인 SVG 자체 제작) |
| 브랜드 컬러 | 라임그린 `#58CC02` | 바이올렛 `#6C4CF1` + 앰버 `#FFB020` |
| 폰트 | Feather Bold | Nunito + Gothic A1 |
| 경로 | 지그재그 원형 노드 | 지그재그 **라운드 스퀘어 노드** + 연결선 트랙 |
| 피드백 | 하단 컬러 시트 | 하단 시트(동일 멘탈모델) + 아이콘/문구 자체 디자인 |
| 재화 | 하트/젬 | 하트/크리스탈 |

기능·인터랙션 모델은 동일하게, **모든 그래픽 자산·컬러·타이포·카피는 자체 제작**.
학습 가능성을 해치지 않도록 정답=초록 / 오답=빨강 같은 보편 신호는 유지.
