# Pingo

듀오링고를 역분석(REA)해 만든 언어 학습 웹앱. **학습 메커니즘은 동일하게, UI·그래픽 자산은 전부 자체 제작**했습니다.

> 데모: 영어 코스 (한국어 사용자용) · CEFR A1~B2 4단계 난이도

## 무엇을 재현했나

| 영역 | 구현 |
|------|------|
| 온보딩 | 학습 목적 → 일일 목표 → 현재 실력 → 시작 지점 선택 |
| 배치 테스트 | 8문제로 난이도를 올려가며 시작 유닛을 추천 |
| 학습 경로 | 섹션 → 유닛 → 노드. 좌우로 감기는 경로, 잠김/현재/완료/복습 상태 |
| 레슨 플레이어 | 상단 진행바 + 하트, 하단 고정 CTA, 정답/오답 피드백 시트 |
| 문제 유형 | 그림 고르기 · 뜻 고르기 · 단어 은행 조립 · 직접 입력 · 듣고 받아쓰기 · 짝 맞추기 |
| 오답 처리 | 하트 1 차감, 틀린 문제는 큐 뒤로 재삽입해 숙달할 때까지 반복 |
| 게임화 | 하트(실시간 회복) · XP · 일일 목표 링 · 스트릭 · 크리스털 · 상점 · 일일 퀘스트 · 주간 리그 |
| 그 외 | 키보드만으로 레슨 진행(숫자·Enter), 라이트/다크 테마, 반응형 |

## 난이도 설계

섹션의 `tier`가 문제 구성을 바꿉니다. 유닛 복습 노드는 한 단계 더 어렵게 취급합니다.

| tier | 과정 | 보기 수 | 미끼 수 | 직접 입력 | 듣기 |
|------|------|--------|--------|----------|------|
| 1 기초 (A1) | 첫걸음 | 3 | 2 | 0% | 20% |
| 2 초급 (A2) | 일상 회화 | 4 | 3 | 15% | 25% |
| 3 중급 (B1) | 실전 영어 | 4 | 4 | 35% | 30% |
| 4 상급 (B2) | 심화 | 5 | 5 | 50% | 30% |

레슨은 "인지(고르기) / 산출(쓰기·듣기) / 짝맞추기"에 각각 몫을 배정해 구성합니다.
미끼 단어는 아직 배우지 않은 상위 난이도에서 끌어오지 않습니다.

## 그래픽

외부 아이콘·일러스트 라이브러리를 쓰지 않습니다. 전부 인라인 SVG로 직접 그렸습니다.

- `src/art/pictograms.tsx` — 46종 플랫 벡터 픽토그램 (64×64 그리드, 라이트/다크 대응 팔레트)
- `src/art/brand.tsx` — 마스코트 "핑고", 로고, UI 아이콘
- 음성은 Web Speech API, 효과음은 WebAudio로 합성 (오디오 파일 없음)

## 개발

```bash
npm install
npm run dev     # http://localhost:5280
npm run build
```

진도·재화는 브라우저 `localStorage`에만 저장됩니다. 서버가 없습니다.

## 구조

```
src/
  art/        픽토그램 · 마스코트 · 아이콘 (자체 제작 SVG)
  data/       코스 콘텐츠 · 퀘스트 · 리그
  engine/     레슨 생성기 · 채점 · 결정적 난수
  state/      전역 상태(리듀서 + localStorage)
  components/ UI 키트 · 레슨 플레이어 · 학습 경로 · 셸
  screens/    온보딩 · 학습 · 퀘스트 · 리그 · 상점 · 프로필 · 결과
  styles/     디자인 토큰 · 컴포넌트 · 화면 레이아웃
docs/
  analysis.md 듀오링고 역분석 기록
```

## 고지

학습 설계와 상호작용 모델은 듀오링고를 참고했지만, 로고·마스코트·일러스트·컬러·타이포·카피는
모두 새로 만든 것이며 듀오링고의 자산을 포함하지 않습니다. 학습 목적의 재구현입니다.
